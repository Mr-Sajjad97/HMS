Yeh poora Hospital ERP Python 3 aur SQLite Central Database mein tayyar kiya gaya hai.
Is ko chalane ke liye kisi extra package (pip install) ki bhi zaroorat nahi hai!

Step 1: Python Install Hona Chahiye
-----------------------------------
Aap ke computer par Python 3 install hona chahiye (https://python.org).

Step 2: Double-Click Se Start Karein (Windows)
----------------------------------------------
Is folder mein mojood file:
   START_PYTHON_ERP_WINDOWS.bat
par Double-Click karein!

Ya CMD / Terminal mein yeh command likhein:
   python hospital_erp_server.py

Step 3: Browser Mein Open Karein
--------------------------------
Yeh khud hi browser mein khul jayega, ya browser mein yeh address likhein:
   http://localhost:5000
